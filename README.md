# PROJECT COSMO ORDER

無料で遊べる銀河探索・産業シミュレーションゲームです。2026年10月10日のASI研究39%停止修正版を公開しています。

[ブラウザで遊ぶ](https://cosm0rder.github.io/cosmo-order/)

[Windows版をダウンロード](https://github.com/Cosm0rder/cosmo-order/releases/latest)

Windows版はZIPをすべて展開して、CosmoOrder.exeを起動してください。CosmoOrder.pckは同じフォルダーに置いてください。

ブラウザ版にはWebGL 2対応ブラウザが必要です。初回は約55 MBを読み込みます。セーブはブラウザに保存されるため、同じURL・同じブラウザで続けてください。プライベートモードやサイトデータ削除でセーブが失われることがあります。

Godot、フォント、音源のクレジットとライセンスは [licenses](licenses/) に収録しています。詳細は [お読みください.txt](お読みください.txt) を参照してください。

ASIが39%付近で止まった場合：同じブラウザでページを再読み込みし、セーブをロードしてください。STAGE 3の「ASI研究・設備整備」から不足工場・TPU・QPUを整備するか、月予算を確認して自動整備をONにします。設備が通電・冷却して稼働すると、保存済みの研究進捗から続けられます。費用・資材・半導体はゲーム内で実際に消費します。
