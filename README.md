# PROJECT COSMO ORDER

無料で遊べる銀河探索・産業シミュレーションゲームです。2026年10月9日の安定性修正版を公開しています。

[ブラウザで遊ぶ](https://cosm0rder.github.io/cosmo-order/)

[Windows版をダウンロード](https://github.com/Cosm0rder/cosmo-order/releases/latest)

Windows版はZIPをすべて展開して、CosmoOrder.exeを起動してください。CosmoOrder.pckは同じフォルダーに置いてください。

ブラウザ版にはWebGL 2対応ブラウザが必要です。初回は約55 MBを読み込みます。セーブはブラウザに保存されるため、同じURL・同じブラウザで続けてください。プライベートモードやサイトデータ削除でセーブが失われることがあります。
